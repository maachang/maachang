# プロジェクト概要
maachang（Bun.serve を使った超最小ローカルフレームワーク）は、Nginx を前面に利用したオンプレミス（物理サーバ）で実行される軽量 Web アプリケーションサーバ環境です。
[minto](https://github.com/maachang/minto) の設計思想（`.mt.js` による動的処理、`JHTML` テンプレート、`filter.mt.js` によるリクエスト共通前処理、`$loadLib` 機構等）を踏襲し、**外部 npm 依存ゼロ（Zero Dependency）**、**ミリ秒起動**、**「ファイル配置 ＝ URL」の直感的なアプローチ** を実現しています。

# インフラ・HTTPS 運用仕様
- オンプレミス本番環境では **Nginx をリバースプロキシとして全面配置** して運用する
- **無料 SSL 証明書 (Let's Encrypt / Certbot)** の利用を標準とする:
  - HTTPS (443) 終端、および HTTP (80) での ACME チャレンジ (HTTP-01) はすべて Nginx 側で一元管理する
  - 証明書自動更新（約2〜3ヶ月毎）時は `nginx -s reload` による無停止反映を行う
  - maachang (Bun.serve) 側はローカルポート（HTTP: localhost:3000等）でリクエストを受け付ける
  - クライアント IP 等の取得は Nginx から渡される `X-Forwarded-For` / `X-Real-IP` を利用する

# 設計原則 & アーキテクチャ

1. **「ファイル配置 ＝ URL」の直感性 (PHP 的アプローチの現代的再定義)**:
   - 複雑な SPA や状態管理、大量の npm 依存を排し、`public/` 配下のファイル構造がそのまま URL に対応するクラシカルで扱いやすい SSR / API 構造を保つ。
2. **AI Native な開発体験**:
   - 1〜2 ファイルで処理と画面描画が完結するため、AI エージェントが迷わず、コンテキストを浪費せず、プロンプト一発で機能追加できる構造を維持する。
3. **ゼロ外部依存 ＆ ミニマリズム**:
   - `node_modules` への安易な依存追加を禁止。Bun の標準機能および SQLite3 (`bun:sqlite`) で完結させる。
4. **コンポーネントの再利用性とシンプル化**:
   - スパゲティコーディングを避け、共通モジュールや `$include` によるテンプレート部品化を活用する。
5. **設定ファイルの JS コメント (JSONC) 対応**:
   - `conf/*.json` では単一行コメント `//`、複数行コメント `/* ... */`、末尾カンマに対応し、`conf/env.json` の値は自動的に `process.env` に展開される。

# 主要コマンド
- **初期セットアップ**: `./bin/initMaachang`（`MAACHANG_HOME` と `PATH` をシェル設定へ登録）
- **新規プロジェクト作成**: `mkmc <project-name>`
- **サーバー起動**: `maachang [-p port] [-h host] [--prod]`
- **JHTML 事前コンパイル**: `mcbuild`
- **テスト実行**: `bun test`
