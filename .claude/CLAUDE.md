# プロジェクト概要
maachang（Bun.serveを使った超最小ローカルフレームワーク） は、Nginx を全面に利用した オンプレミス(物理サーバ)で実行されるローカルWebアプリサーバ環境です.
機能としては「minto=${MINTO_HOME}=https://github.com/maachang/mintoで利用されている サーバモジュールの最低限必要な内容を踏襲した」ローカルWebアプリサーバ環境で、ここでの「jhtml機能」や「filterやmt.jsファイル」を踏襲します。
また、RDBMSは選択されない場合は bun 標準の sqlite3 を利用します。

# インフラ・HTTPS運用仕様
- オンプレミス本番環境では **Nginx をリバースプロキシとして全面配置** して運用する
- **無料SSL証明書 (Let's Encrypt / Certbot)** の利用を標準とする:
  - HTTPS (443) 終端、および HTTP (80) での ACME チャレンジ (HTTP-01) はすべて Nginx 側で一元管理する
  - 証明書自動更新（約2〜3ヶ月毎）時は `nginx -s reload` による無停止反映を行う
  - maachang (Bun.serve) 側はローカルポート（HTTP: localhost:3000等）でリクエストを受け付ける
  - クライアントIP等の取得は Nginx から渡される `X-Forwarded-For` / `X-Real-IP` を利用する
